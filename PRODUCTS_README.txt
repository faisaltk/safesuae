HOW TO ADD A NEW PRODUCT LATER
1. Copy one of the existing product HTML files inside the products folder.
2. Rename it, for example: hotel-safe.html
3. Change the product name, category, description, features and WhatsApp message.
4. Add a new card to products/index.html.
5. Add the same card to the Products section in index.html if you want it featured on the homepage.
6. Upload the changed files/folders to GitHub.

PRODUCT PHOTOS
The current pages use placeholders so the site works immediately. When you have the real product photos, add them and replace the placeholder block with an <img> element.

IMPORTANT
Keep CNAME in the repository root and do not delete it. Keep index.html, style.css, script.js and logo.jpg in the repository root.
