# SafeS UAE demo website

This is a plain HTML/CSS demo. It has no paid hosting requirement.

## Edit
Open `index.html` in any text editor to change the words, contact details and sections.
Open `style.css` to change the design.

## Publish for free
A static site like this can be hosted for free using services such as GitHub Pages or Cloudflare Pages. Your domain `safesuae.com` can then be connected through DNS.

The contact form in this demo is only visual; it does not send email until a form service/backend is connected.
